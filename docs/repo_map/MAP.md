# 仓库地图

## 目录作用

- `docs/repo_map/docs/MAP.md`：长期文档路由；处理任务包、归档文档、反模式和长期说明时进入。
- `docs/repo_map/source/MAP.md`：Python 源码路由；修改核心库或 CLI 行为时进入。
- `docs/repo_map/skills/MAP.md`：OpenHarness 技能路由；修改 `using-openharness` 技能、阶段指令或模板时进入。
- `docs/repo_map/config/MAP.md`：安装和项目配置路由；修改安装脚本、项目版本、依赖或命令入口时进入。
- `docs/repo_map/tests/MAP.md`：测试路由；选择验证范围、补充回归测试或排查测试失败时进入。
